# Changelog

## 1.0.0 — 2026-10-11

- Offline JPEG/PNG/WebP batches with preview by default and explicit apply.
- Bounded aspect-ratio resizing without upscaling, EXIF orientation, alpha-aware encoding, metadata removal.
- Separate outputs, collision suffixes, opt-in recursion, and source preservation.
- Per-image errors and JSON reporting with defined exit codes.
- 25 regression tests, synthetic demo, bilingual README, and a six-job Windows/Ubuntu CI matrix.

Future work is tracked in GitHub issues. This release does not claim real-world adoption or external contributions.
